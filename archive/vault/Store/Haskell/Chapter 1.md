# Summary

1. A function is something that transforms its inputs to an output.
2. a type is a collection of objects of a `similar sort` e.g. whole numbers or pictures
3. every object has a clearly defined type, and we state this type on making a definition
4. functions defined in a program are used in writing expressions to be evaluated by the implementation
5. the values of expressions can be found by performing calculation by hand or by using GHCi
