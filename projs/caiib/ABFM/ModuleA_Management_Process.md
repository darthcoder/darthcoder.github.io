## The Master Loop (Read This First)

```
PLAN → ORGANIZE → STAFF → DIRECT → CONTROL → back to PLAN
```

Every question in Module A is a node on this loop. When lost, ask:
**"Which step of the loop is this question about?"**

IIBF's manager is always rational, systematic, and process-driven.
The exam will never endorse intuition over planning, or action before measurement.

## Part 1: Basics of Management

### What Management Actually Is (IIBF Version)

```
Management = getting things done through people, efficiently AND effectively.

Efficiency = doing things right (minimum waste)
Effectiveness = doing the right things (right objective)
```

> **Exam trap:** "A good manager maximises efficiency" → WRONG.
> Efficiency without effectiveness = doing the wrong thing very well.
> **If forced to choose: Effectiveness > Efficiency.**

### Schools of Management Thought

| School | Core Idea | Exam Keyword |
|---|---|---|
| **Scientific Mgmt** (Taylor) | One best way, time-motion studies | Efficiency, standardisation |
| **Administrative Mgmt** (Fayol) | 14 principles, universal functions | Unity of command, scalar chain |
| **Human Relations** (Mayo) | People = social beings | Morale, informal groups, Hawthorne |
| **Systems Approach** | Org = open system with inputs/outputs | Interdependence, environment |
| **Contingency Approach** | No one best way — it depends | Context, situation, flexibility |

**Elimination rule:** Productivity via time studies → Taylor. Worker morale/group dynamics → Mayo. Universal principles → Fayol. "It depends on the situation" → Contingency.

### Fayol's 14 Principles — The Exam Shortlist

Don't memorise all 14. Know these six:

```
1. Division of Work       — specialisation = efficiency
2. Authority = Responsibility — you can't have one without the other
3. Unity of Command       — one employee, ONE boss (not two)
4. Unity of Direction     — one plan per objective (not per person)
5. Scalar Chain           — hierarchy; can bypass in emergency ("gang plank")
6. Esprit de Corps        — team spirit is management's responsibility
```

> **Exam favourite confusion:** Unity of Command ≠ Unity of Direction.
> Command = one boss per person. Direction = one plan per goal. Different levels.

### Business Environment Analysis

```
SWOT: Internal (Strengths, Weaknesses) + External (Opportunities, Threats)
PESTLE: Political, Economic, Social, Technological, Legal, Environmental
```

IIBF rule: Strategy must respond to the external environment. Ignoring environment = wrong answer.

## Part 2: Planning

### The Planning Heuristic

```
Planning = deciding in advance: WHAT + HOW + WHEN + WHO + WHERE
```

Planning is always the FIRST function. Without it, all others break.

### Types of Plans

| Type | Horizon | Characteristic |
|---|---|---|
| **Strategic** | 3–5 years | Broad, directional, set by top management |
| **Tactical** | 1–2 years | Bridge between strategy and operations |
| **Operational** | < 1 year | Specific, measurable, day-to-day |

**Heuristic:** Vague + future-oriented + top management = strategic. Specific + numbers + short-term = operational.

### MBO (Management by Objectives)

IIBF loves MBO. Three things the exam always tests:

```
1. Who sets objectives?   JOINTLY (manager + subordinate) — NOT top-down
2. Good objective = SMART (Specific, Measurable, Achievable, Realistic, Time-bound)
3. Benefit = clarity + motivation (people work harder for self-set goals)
```

> **Elimination rule:** Any option saying "manager sets targets for subordinate" → eliminate.
> MBO = participative by definition.

### Contingency Planning

Plan for what could go wrong. IIBF treats contingency planning as prudent, not pessimistic.

> Same mental model as Basel buffers in BFM — prepare for the tail risk.

### Decision Making

```
Rational model: Define problem → Alternatives → Evaluate → Choose → Implement → Review
```

IIBF always picks the systematic rational option over "gut feel" or "experience."

**Exception — Satisficing (Herbert Simon):** In real life, managers choose "good enough" not "optimal" due to limited information (bounded rationality). IIBF acknowledges this. It is NOT a wrong answer when the question involves incomplete information.

## Part 3: Organizing

### The Organizing Heuristic

```
Organizing = matching tasks → people → authority → accountability
```

### Span of Control

```
Wide span  = flat org = more delegation = works for routine tasks
Narrow span = tall org = more supervision = works for complex/novel tasks
```

> Digital, standardised tasks → wide span. Specialised, complex tasks → narrow span.

### Organisation Structures

| Structure | Grouped By | Strength | Weakness |
|---|---|---|---|
| **Functional** | Function (HR, Finance, Ops) | Specialisation, efficiency | Silos, slow decisions |
| **Divisional** | Product / Geography | Accountability per unit | Duplication of resources |
| **Matrix** | Both function + project | Flexibility, dual expertise | Violates unity of command |

> **Matrix heuristic:** Matrix structure's known weakness = TWO bosses (violates Fayol's Unity of Command). If a question asks "what is the disadvantage of matrix?" → unity of command conflict.

### Authority, Responsibility, Accountability

```
Authority      = right to command (can be delegated)
Responsibility = obligation to perform (can be delegated)
Accountability = answerability for outcome (CANNOT be delegated — stays with delegator)
```

> **Exam favourite:** "When a manager delegates, he is relieved of accountability" → **FALSE.**
> Accountability is non-transferable. The delegator is still on the hook.

### Organisational Change

IIBF's change management sequence:
```
Unfreeze (create need for change) → Change (implement) → Refreeze (stabilise)
```
Resistance to change is normal and should be managed, not punished.

### Conflict

```
Functional conflict  = constructive, improves decisions (acceptable)
Dysfunctional conflict = destructive, harms performance (needs resolution)
```

IIBF rule: Conflict is not always bad. The goal is to manage and channel it, not eliminate it.

## Part 4: Staffing

### The Staffing System

```
Recruit → Select → Induct → Train → Appraise → Develop → Retain
```

### Key Elimination Rules

```
1. Training   = improving current job performance
   Development = preparing for FUTURE roles
   (They are NOT the same — exam tests this distinction repeatedly)

2. Performance Appraisal primary purpose = DEVELOPMENT, not punishment
   If an option says "identify poor performers to fire them" → eliminate as primary purpose

3. Recruit = attract pool of candidates
   Select    = filter the pool
   Sequence always: Recruit FIRST, then Select

4. Internal recruitment = morale + faster onboarding + known quantity
   External recruitment = fresh ideas + new skills + no internal politics
   Neither universally better — "it depends" is IIBF's answer
```

### HRM vs. HRD

| HRM | HRD |
|---|---|
| Administrative (pay, compliance, headcount) | Developmental (skills, growth, capability) |
| Short-term, reactive | Long-term, proactive |
| Maintains current state | Builds future capability |

> IIBF exam: When the question is about employee growth and organisational capability → HRD is the "better" concept.

### Knowledge Management

```
Tacit knowledge  = in people's heads (hard to transfer)
Explicit knowledge = documented (easy to transfer)
```

Knowledge management = converting tacit → explicit + sharing across organisation.

## Part 5: Directing

### The Directing Heuristic

```
Directing = making plans happen through people:
Leadership + Motivation + Communication + Supervision
```

### Leadership Styles

| Style | Approach | IIBF's View |
|---|---|---|
| **Autocratic** | Leader decides alone | Acceptable only in crisis or with incompetent team |
| **Democratic/Participative** | Group involved in decisions | **Default correct answer** in normal conditions |
| **Laissez-faire** | Hands off | Acceptable only with expert, self-motivated team |

> **IIBF bias:** Participative = modern, correct, recommended.
> Autocratic = outdated. Laissez-faire = abdication unless team is expert.

### Motivation Theories — The Exam Shortlist

| Theory | Core Idea | Trigger Words |
|---|---|---|
| **Maslow's Hierarchy** | 5 levels: Physiological → Safety → Social → Esteem → Self-actualisation | "Lower to higher", "hierarchy of needs" |
| **Herzberg Two-Factor** | Hygiene factors vs. Motivators | "Salary doesn't motivate", "job enrichment" |
| **McGregor X/Y** | Theory X = people are lazy; Theory Y = people want to work | "Assumptions about human nature" |
| **McClelland** | Need for Achievement / Power / Affiliation | "nAch", "nPow", "nAff" |

### Herzberg — The Exam Favourite

```
Hygiene factors (salary, job security, working conditions):
→ Their ABSENCE causes dissatisfaction
→ Their PRESENCE does NOT create motivation — only removes dissatisfaction

Motivators (recognition, achievement, growth, responsibility):
→ Their PRESENCE creates genuine motivation
→ Their ABSENCE does not necessarily cause dissatisfaction
```

> **Practical heuristic:** Giving a salary hike → removes complaints, doesn't motivate.
> Giving recognition + responsibility → actually motivates.
> Exam will test: "Company raised salaries but motivation didn't improve" → Herzberg explains this.

### Communication

```
Formal channels:   official, documented, slow, accountable
Informal (grapevine): fast, unofficial, always exists, cannot be killed
```

> IIBF rule: Management should work WITH informal channels, not against them. Suppressing the grapevine doesn't work — redirect it.

**Communication barriers IIBF tests:**
```
Semantic  = words mean different things to sender/receiver
Perceptual = filtered through personal bias
Physical  = noise, distance
Organisational = too many hierarchy levels distort message
```

## Part 6: Controlling

### The Controlling Heuristic

```
Controlling ≠ punishing people
Controlling = measuring actual vs. planned → correcting deviations → feeding back into next plan
```

### The Control Process

```
1. Set standards        (derived from the Plan)
2. Measure actual performance
3. Compare actual vs. standard
4. Identify deviations
5. Analyse causes
6. Take corrective action
7. Feedback → revise next plan
```

### Types of Control

| Type | Timing | Purpose | Example |
|---|---|---|---|
| **Feedforward** | Before action | Prevent errors | Training before task |
| **Concurrent** | During action | Real-time correction | Supervisor on floor |
| **Feedback** | After action | Learn and correct | Performance review |

> **Heuristic:** "Prevent errors before they happen" → feedforward. "Fix while doing" → concurrent. "Learn from what happened" → feedback.

### Management by Exception

```
Routine deviations → handled at lower level (don't escalate)
Significant deviations only → escalate to higher management
```

IIBF loves this principle. It appears in management AND in banking supervision (same logic as materiality in audit).

### Relation Between Planning and Controlling

```
Planning sets the standards.
Controlling measures against those standards.
Without planning, controlling has nothing to measure.
Without controlling, planning has no feedback loop.
```

> They are two sides of the same process — not separate functions.

### Control Techniques

| Technique | What It Is |
|---|---|
| **Budgets** | Financial control standard |
| **MBO** | Controls via agreed objectives |
| **PERT/CPM** | Project timeline control |
| **Statistical QC** | Variance-based production control |
| **Break-even Analysis** | Cost-volume-profit control |

## Master Meta-Heuristic: Module A

```
Q: What should a manager do first?
→ Plan. Always plan before acting.

Q: Who retains accountability when work is delegated?
→ The delegator. Accountability cannot be transferred. Ever.

Q: What's the best leadership style?
→ Participative/democratic — unless it's a crisis or the team is incompetent.

Q: Why didn't the salary increase improve motivation?
→ Herzberg. Salary is hygiene, not a motivator.

Q: What is controlling?
→ Measuring deviations and correcting them. Not punishing people.

Q: Is conflict always bad?
→ No. Functional conflict is healthy. Dysfunctional conflict needs resolution.

Q: Training vs. Development?
→ Training = current job. Development = future role.
```

### The IIBF Management Worldview

```
Process > intuition
Delegation > hoarding authority
Participation > autocracy
Development > punishment
Measurement > gut feel
Effectiveness > efficiency (when forced to choose)
The Board is always ultimately responsible
No plan = no control = no management
```
