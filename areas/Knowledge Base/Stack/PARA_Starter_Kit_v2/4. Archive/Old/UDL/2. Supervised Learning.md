
## For regression

$$ L[\phi] = \Sigma (\phi_0 + \phi_1 x_i - y_i)^2 $$

Why this form of Loss? Why not a vector $L_i[\phi]$ and the loss is minimized when this is at a minimum. 

> That is what that loss is, its the absolute value of the Loss vector, that I think is the $L_2$ loss i think. There are other ways of defining loss I think but that seems to be a pedantic point.

>[!Note]
>What about using non-Euclidean metrics for regression?

> When we are overfitting, it is a sign that the space that relates the $y_i$ and $x_i$ is not Euclidean, so we can instead of trying varying fits try to vary the curvature of the space itself, so that the Loss metric is different. This can improve the fit.
